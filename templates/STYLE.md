# STYLE · 极光夜（Aurora Night）

> 一份风格说明，不是一句形容词。写清：长什么样、怎么动、听起来什么样、什么不能做。

## 一句话

**黑到发蓝的夜空，光从天上垂下来；所有颜色都是发光，所有动作都是缓慢的。**

## 适用

- 夜空、极地、高纬度、太阳风、磁场、发光生物；
- 需要“安静、辽阔、冷”的题材；
- 不适合：快节奏、强信息密度、暖色生活题材。

## 画面

| 项 | 规定 |
|---|---|
| 底 | `#02040A` → `#04101C`，纵向渐变，不要纯黑 |
| 主体光 | 极光绿 `#6BFFB0`，次光紫 `#9B7BFF`，都带 20–30px 的辉光 |
| 辅助 | 星点 `#CFE3F7`，透明度 0.4–0.8，随机分布（固定种子） |
| 前景 | 山脊或雪原剪影，纯黑，压在画面下缘 30% |
| 文字 | 白色 `#EAF2FF`，大字重；关键词染绿或紫 |
| 禁止 | 高饱和红、黄；大面积白；卡通轮廓线 |

## 动效

| 项 | 规定 |
|---|---|
| 光帘 | 竖向细带，宽度 20–30px，高度随机，透明度 0.14–0.24，缓慢起伏 |
| 节奏 | 一个动作 1.2–2.4 秒，全部 ease-in-out |
| 粒子 | 沿磁力线匀速下滑，不弹跳 |
| 转场 | 溶解或推近，不做硬切 |
| 禁止 | 快速闪白、频闪、缩放抖动 |

## 声音

| 项 | 规定 |
|---|---|
| BGM | 60–70 BPM，A 小调，pad 为主，钢琴稀疏 |
| 音效 | 只在“粒子进入大气”“颜色切换”两处，轻、短、低频 |
| 人声 | 中速，句间留 0.5 秒以上，不要压过画面 |

## 版式

- 五区：左上编号 / 右上指标 / 中部画面 / 下部注释 / 底部字幕；
- 标题最多两行，字重 900，行距 1.2；
- 关键数字（100 km、200 km）单独放大，做节奏锚点。

## 自检

- [ ] 全片最亮的地方是极光，不是文字；
- [ ] 没有一处纯黑死区；
- [ ] 光帘至少出现三种高度；
- [ ] 颜色只表达“高度”，不表达好坏；
- [ ] 任意 2 秒内有可见变化。
