# 发布文案模板

只给结构与句式，内容按自己的项目填。方括号里是要替换的部分。

---

## 一、仓库 / 项目简介

**句式**

> 【一句话说清它是做什么的】：【输入什么】→【输出什么】。

**示例（结构演示，不是成品）**

- 用【技术栈】做【内容类型】：【输入】→【输出】。
- 【动词】一个【单位】的工具，把【原本很慢的事】变成【很快的事】。

**要点三条（每条一句，不超过 25 字）**

| 位置 | 写什么 |
|---|---|
| 1 | 最反直觉的那个做法 |
| 2 | 用户最能感知的那个结果 |
| 3 | 可复用的资产（模板 / 风格 / 脚本） |

---

## 二、短文案（朋友圈 / 即刻 / 小红书，80–120 字）

**结构**

```
【做了什么】。
【最省事的一步是什么】——【具体到一个动作、一个数字】。
【可选的对比】：以前【X】，现在【Y】。
【结尾一句邀请或指向】。
```

**句式模板**

- 做了个【东西】：【一句话功能】。
- 【输入】写完，跑【几条命令】，出来【结果】。
- 以前【耗时】，现在【耗时】。
- 最麻烦的不是【显眼的部分】，是【不显眼的部分】。

**注意**：短文案只放一个数字。数字多了没人记。

---

## 三、长文（知乎 / 公众号 / 掘金）

**结构（四段，每段 150–250 字）**

| 段 | 作用 | 写什么 | 不写什么 |
|---|---|---|---|
| 1 问题 | 让人点头 | 一个具体到次数、时长的痛点 | 不写"随着时代发展" |
| 2 转折 | 给出做法 | 你换掉的那个环节 + 为什么 | 不列技术名词堆砌 |
| 3 方法 | 证明可行 | 步骤清单（4–6 步）+ 一个关键细节 | 不写"非常简单" |
| 4 结果 | 收尾 | 一个可验证的结果 + 一句限制条件 | 不写"未来可期" |

**每段的开头句式**

- 问题：`【场景】里，【某个动作】要重复【次数】遍。`
- 转折：`后来换了个做法：`【新做法】。
- 方法：`现在的流程是：` + 有序列表。
- 结果：`改【单位】的成本从【旧值】降到【新值】。`

**结尾可选三种**

1. 限制：`目前只适合【范围】，超出这个范围【做不到什么】。`
2. 邀请：`模板在【位置】，改几个参数就能用。`
3. 反问：`如果你的场景是【另一种】，你会怎么做？`

## 四、短视频口播引子（前 3 句）

**结构**：一句反常识 → 一句方法 → 一句结果。

```
以前【做某事】要【时长】，现在【时长】。
因为我把【环节】换成了【做法】。
【一句话说清做法】。
```

**变体**

| 变体 | 首句 |
|---|---|
| 反常识 | `【大家以为的做法】其实是最慢的。` |
| 数字 | `一条【内容】有【N】个卡点，手动要拖【时长】。` |
| 结果前置 | `【结果】我用了【时长】，方法只有三步。` |

---

## 五、一句话（标签 / 副标题）

三个变体，按场景挑：

| 变体 | 句式 |
|---|---|
| 极短 | `【做什么】，改一【单位】就重出【结果】` |
| 技术向 | `【技术 A】+【技术 B】组成的【内容】流水线` |
| 结果向 | `【数量】个【产出】，全部可复现` |

---

## 六、发之前检查

- [ ] 只留一个数字
- [ ] 没有"颠覆""革命""史上最"这类词
- [ ] 第一句能让人知道"跟我有什么关系"
- [ ] 结尾给了一个具体动作或一个具体位置
- [ ] 全文没有一段是空话（删掉试试，不通就是空的）

---

## 七、标题模板（Vibe 知识大赏）

### 公式

```
Vibe知识大赏｜【反常识现象】，不是【大众以为的原因】，是因为【真实机制】。

#Vibe知识大赏 #领域 #关键词
```

三个空位对应三件事：

| 空位 | 写什么 | 要求 |
|---|---|---|
| 反常识现象 | 一句能被验证的事实 | 有数字或具体动作 |
| 大众以为的原因 | 观众此刻脑子里的解释 | 一定是错的 |
| 真实机制 | 一句话讲清真正原因 | 不用术语，像比喻 |

### 示例

```
Vibe知识大赏｜ 三岁前的事记不住，不是因为忘得多，是因为那会儿你的大脑，还在盖房子。
#Vibe知识大赏 #记忆 #大脑
```

### 变体

**A. 时间跨度版**（适合有历史的故事）
```
Vibe知识大赏｜【现象】吵了【N】年，不是因为没人研究，是因为【难点】。
```

**B. 人物版**（适合有具体发现者的选题）
```
Vibe知识大赏｜ 1963 年那个孩子没算错，不是因为运气，是因为【机制】。
```

**C. 机制版**（适合原理类）
```
Vibe知识大赏｜【现象】，不是因为【直觉解释】，是因为【机制】。
```

### 注意

- 「不是」后面必须是**观众真会那么想**的解释，否则整句失效
- 「是因为」后面**不能出现术语**，出现就换比喻
- 标题总长控制在 40 字以内，超过会被折叠
- 标签固定 3 个：一个大赏标签 + 一个领域 + 一个具体词
