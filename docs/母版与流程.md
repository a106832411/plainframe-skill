# 母版与流程（学自 vibe-knowledge）

> 来源：[andyhuo520/vibe-knowledge](https://github.com/andyhuo520/vibe-knowledge)（MIT）。
> 它把「一条知识短片」拆成：**选母版 → 查证 → 写稿 → 三次确认 → 配音 → 代码成片 → 质检 → 发布包**。
> 我们过去缺的正是前半段：直接写 24 句，没有母版、没有事实清单、没有中途确认。

## 一、六种母版（先选母版，再写句子）

| 母版 | 适合 | 时长 | 骨架 |
|---|---|---|---|
| A 猜谜概念片 | 一个抽象概念（熵、本福特定律、贝叶斯） | 3:30–4:30 | 冷开场给半句话 → 点题 → 量化 → 两个熟悉例子 → 亲身体验 → 拉到宇宙 → 边界 → 落回观众 → 回环 |
| B 两难选择片 | 历史事件、博弈、心理实验 | 2:55 固定 | 离奇事实 → “换你” → 片头 → 前情 → 经过 → 等待 → 揭晓 → 反转 → 对照组 → 回问 |
| C 痛点原理片 | 日常困扰 × 冷门原理 | 2:00–2:30 | 反常 → 谁偷走了 → 原理（人名+年份）→ 一个贯穿道具 → 代入一个下午 → 3 秒解法 → 第二个反常 → 治愈 |
| D 一条主线片 | 学科体系、技术史、一个家族 | 约 3:00 | 碎片 → “其实有一条线” → 线穿 5–7 个节点 → 收成网 → 问观众 |
| E 闯关片 | 考试题型、方法论 | 4–6 分钟 | 地图 → 每关题干/陷阱/正解/秘籍卡 → 最终 Boss → 一屏秘籍总表 |
| F 六面轮转片 | 哲学流派、观点对比 | 45–60 秒 | 一个问题 → 六种答案（人名·书名·年份+原话）→ “没有一面是纯色” → 你转到哪面 |

## 二、所有母版共用的七条

1. **前 3 秒让观众参与**：猜一个字、选一个按钮、认一个日常场景；不要先上标题、不要自我介绍。
2. **标题延后**：钩子讲完再出片头。
3. **一个主道具贯穿全片**：概念变了道具变形，不换道具。
4. **每个事实挂出处**：年份、人名、数字、引文都要有来源；示意画面标“为示意”；说法有分歧就两说并列。
5. **画面只放关键词（≤8 字）、数字、出处**，整句交给旁白和字幕。
6. **每章一句金句收尾**，能截图。
7. **结尾回扣开头，把问题交回观众**（评论区互动）。

## 三、四道确认（不能一口气做完）

| 确认 | 给用户看什么 |
|---|---|
| 确认 1 | 选题、母版、**时长**（速览/精讲/标准/深挖四档，写清每档能讲多细、砍掉什么）、风格 |
| 确认 2 | 旁白稿 + 分镜（每拍一句话、一个画面） |
| 确认 3 | 成片 + 发布包（标题、话题、简介、封面） |

跳过确认必须用户明说，并写进项目文件。

## 四、事实清单（facts.md）

开工第二步就建 `facts.md`，一行一个事实：

```
| 事实 | 数值/表述 | 出处 | 状态 |
|---|---|---|---|
| 极光高度 | 绿色约 100–150 km |  NOAA / 教科书 | 已核 |
| 极光颜色 | 红为氧 200 km 以上 | 同上 | 已核 |
| 极光成因 | 太阳风粒子沿磁力线 | 同上 | 已核 |
```

写稿时只允许引用表里的事实；表里没有的，先去查，查不到就不写。

## 五、质检五项

1. **接触表**：每场抽一帧，拼成一张，逐场看；
2. **OCR 回读**：把画面上的文字读回来，和 `facts.md` 对照，防止写错数字；
3. **响度**：人声与 BGM 的比例固定（我们现在是 BGM 低 10 dB 左右）；
4. **冻结检测**：连续 4 秒无变化就报警；
5. **BGM 检测**：确认全片有 BGM、没有断。

## 六、接进 plainframe

```
选题 → 母版+时长（确认1） → facts.md → 按母版写旁白 → 分镜（确认2）
     → lines.json → base.tpl → 配音 → 渲染 → 质检 → 成片+发布包（确认3）
```

- 我们现有 24 句的写法，本质是母版 C（痛点原理片）的压缩版；换母版就要换节拍，不是改几句话。
- 口播版保留旁白；无旁白版可以把整句放进字幕，画面只留关键词。
- 帧率默认 30fps；需要更顺的推拉时用 60fps（`film.js` 那套是 60fps 逐帧）。

## 七、我们现在的差距（照这份材料自查）

| 项 | 他们 | 我们 |
|---|---|---|
| 母版 | 六种，先选后写 | 只有一种“24 句” |
| 时长 | 四档，先定 | 写完才知道多长 |
| 事实 | facts.md，逐条出处 | 凭记忆，偶尔查 |
| 确认 | 三次 | 常常一口气做完 |
| 道具 | 一个贯穿全片 | 每场换新东西 |
| 质检 | 接触表 + OCR + 冻结 + BGM | 只抽帧看 |
