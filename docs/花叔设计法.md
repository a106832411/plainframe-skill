# 花叔设计法 · 移植到 plainframe

> 学自 [alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design)（MIT，v3.0）。
> 只取能直接治我们毛病的那几条：**先出三个方向、别用默认审美、素材先行、六维评审、检查点物化成文件。**

## 一、根子上的一条：你是设计师，不是写 HTML 的

HTML/GSAP 只是媒介。判断标准是「别人看到会问这哪个工作室做的」，不是「AI 做得还行」。

**我们过去的毛病：** 每个片子只做一个方向，做完才拿去给用户看；用户说不对，就换一种颜色再做一个。
这不是设计流程，是碰运气。花叔的做法是反过来：**候选多，交付少。**

## 二、三方向门（100%，指定风格也不豁免）

任何会产出新视觉的任务，先做**六个候选**，挑三个最强、彼此最不一样、不撞我们自己旧片的，做成**完整初稿**（每版至少一张真实渲出的关键帧），摆出来给用户选。用户选定才做全片。

- 六个候选的三条来源：
  1. **最佳设计师**：预算无限时最适合这个题材的设计师，用他的思维从头做；
  2. **现实参照**：找同题材里核实过的出色作品，截下图来亲眼看，再拆它的设计语言；
  3. **风格轮盘**：从风格库里抽，先看样张。
- 三个完整方向**必须彼此不同**：不能三版都是暖纸衬线、也不能三版都是深底单点缀。
- 最多一版「用力过头」（整页做成道具、套一个万能隐喻）——去掉这个手法信息反而更清楚，那就是过头。
- **摆出来就停**，结束回合等用户选。用户说「继续」是进入下一步，不是跳过低稿。

**落地到本 skill：** 新片开工前，先交 `设计方向.md`（六格缩略 + 三方向关键帧截图 + 每版一句定位），用户选定后再写 `base.tpl`。

## 三、默认审美禁区（AI 味最重的几样）

不加约束时，模型会滑向这些；它们不丑，但和题材无关地出现，就是「AI 做的」：

- 暖奶油底 + 高反差衬线标题 + 陶土色点缀；
- 每个标题上一行全大写小标签；
- `A · B · C` 中点连接、按钮尾巴的 `→`；
- `01 / 02 / 03` 编号（内容不是序列时）；
- 紫渐变、emoji 图标、左彩条圆角卡片；
- **用 SVG 画人**（我们上一版正好踩了这条）。

外观家族本身不是问题——暖纸衬线、深底单点缀、细线报纸、卡片套件都好看；问题是**不同项目反复用同一个**。每次都要从题材里重新长出来。

## 四、素材先行

每个方向先定**主角素材**：真图、生成图、程序化材质、数据图像、实物仿制、巨字。别让三个方向都是纯排版。
内容必需的图先取齐再设计；具名产品的 logo 逐个取到。缺能力就降级，但不许用「画一个」顶上——除非这个方向本来就是插画。

## 五、可读性底线（任何风格不豁免）

- 网页正文 ≥14px、标签 ≥12px；
- deck 正文 ≥24px、标签 ≥16px；
- 手机上看的 1080 宽长图：正文 ≥36px、标签 ≥28px（画布像素）；
- 正文对比度 ≥4.5:1；留白是构图，不是内容缺席。

## 六、六维评审（交付前自评，1–10 分）

| 维度 | 看什么 |
|---|---|
| 概念/立意 | 这个画面有没有一个说得出的想法，还是只是「好看」 |
| 哲学一致性 | 选的风格，每个细节都有依据吗，有没有混进别的风格 |
| 视觉层级 | 标题/正文对比 ≥2.5 倍；眯眼看层级还在；3–4 个清晰层级 |
| 细节执行 | 8pt 网格、同类间距一致、颜色 ≤3–4 种、字体 ≤2 种、对齐精确 |
| 功能性 | 删掉任何一个元素会变差吗？关键信息在最显眼处吗 |
| 创新性 | 有没有一个别人没这么用过的处理 |

**常见问题 Top 10（按我们踩坑频率排序）：** AI 科技 cliché、字号层级不足、颜色过多、间距不统一、留白不足、字体过多、对齐不一致、装饰大于内容、赛博霓虹滥用、信息密度与载体不匹配。

## 七、Gate 文件（文件不在 = 环节没做）

| 文件 | 什么时候必须有 |
|---|---|
| `设计方向.md` | 新片开工前：六候选、三方向关键帧、用户选定的原话 |
| `分镜.md` | ≥20 秒的片子开工前 |
| `brand-spec.md` | 涉及具体品牌/产品时（logo、产品图、UI 截图） |

跳过必须用户明说，并写进对应文件。

## 八、和现有流程的接法

```
选题 → 文案 → 设计方向（六选三，三张关键帧）→ 用户选 → 分镜 → base.tpl → 配音 → 渲染 → 六维评审 → 交付
```

- 文案仍然先定，但**画面方向不再由我一个人拍板**；
- 风格库见 `docs/封面与标题.md` 与 `style-library/`（工作区），每次换题材重新选，不默认暗色；
- 旧片的外观（暖金暗场、冷色、米白病历）都记进「外观账本」，下次主动避开重复。
