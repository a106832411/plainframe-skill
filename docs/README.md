# docs 索引

仓库里文档不少，先看这一页，知道该读哪份。

## 根目录的四份入口文档

| 文件 | 是什么 | 什么时候读 | 打架时听谁的 |
|---|---|---|---|
| `README.md` | 门面：这是什么、给谁、怎么装 | 第一次来 | 细节以 `SKILL.md` 为准 |
| `SKILL.md` | **唯一权威**手册 | 做片子 | **以它为准** |
| `MEMORY.md` | 一页速查，SKILL 的压缩版 | 每次开工前扫一遍 | 与 SKILL 不一致时，改 MEMORY |
| `CHECKLIST.md` | 出片前的勾选清单 | 交片前 | 执行项以它为准 |

`MEMORY.md` 是索引不是手册：它只放判据，不解释原因。两边说法不一致，就是 MEMORY 该更新了。

## 建议的阅读顺序

```
第一次：README → SKILL 第一、二节（工作流 + 风格）
开工：  MEMORY（一分钟）→ 流程/母版与流程 或 流程/锚词与重拍
做片：  SKILL 第三~七节（动效引擎、文字、时间线、声音）
交片：  CHECKLIST → tools/qa.py → tools/contact_sheet.py
发布：  发布/发布包
```

## 一条规矩

**同一件事只在一处定义。** 标题与话题只在 `发布/发布包.md`；字幕安全区只在 `SKILL.md` 第四节；静止阈值以 `tools/qa.py` 的 2 秒为准。
发现两处都在讲同一件事，删一处、留一句指路——别让两份同时改。
