# 与 hyperframes-vibe-169 的边界

本仓库把 `hyperframes-vibe-169` 当**外部参考**，不并进来。原因不是它不好，是两者的组合架构不同，硬合会同时维护两条渲染管线。

| | 本仓库 plainframe-skill | hyperframes-vibe-169 |
|---|---|---|
| 是什么 | 单文件组合 + 构建脚本 | 子组合 + 手写时间线 |
| 入口 | `index.html`（由 `base.tpl` + `build.py` 生成） | `index.html` 挂 `compositions/scene-*.html` |
| 风格 | 18 套配色与构图骨架 | 3 个"世界"（鎏金暗场 / 寓言 / 夜曲） |
| 上游 | 自己这套 | HyperFrames（HeyGen 开源，Apache-2.0） |

---

## 一、硬冲突：两种组合架构，不能混写

| 维度 | plainframe | vibe-169 |
|---|---|---|
| 场景单位 | `<section class="f" id="sN">`，**不带** `data-start` | `class="clip"` + `data-start` + `data-duration` |
| 时间线从哪来 | `build.py` 按音频实测或字数推出来 | 手写在每个场景文件里 |
| 场景文件数 | 一个 `index.html` | `compositions/scene-1…5.html` 多个 |
| 音频 | `mix.py` 后期 ffmpeg 合轨 | `<audio>` 元素交给 hyperframes 混 |
| 改一章 | 改 `lines.json` 重跑全片 | 只改那一个场景文件 |

**混用的后果（都试过）**：

- 给 `.f` 场景加 `data-start` → hyperframes 把它当 clip，到点整场被隐藏，`cut()` 的淡入淡出直接失效；
- 把 `build.py` 生成的 `index.html` 拆成子组合 → `SUBS`、`cut()`、`data-duration` 回写全部要重写，等于换框架；
- 两边各写一半 → lint 不一定报错，但渲染出来一半场景不出现，且很难查。

**取舍**：默认用 plainframe。只有满足下面任一条，才值得切到 vibe-169 那套：

1. 片长 > 3 分钟，且每一章要独立迭代；
2. 多人并行改不同章节，没法共用一个 `lines.json`；
3. 需要 hyperframes 的 clip 级工具（`inspect` / `snapshot --composition` 按场景取样）。

---

## 二、真冲突：四条规则不一致

| 规则 | plainframe | vibe-169 | 采纳 |
|---|---|---|---|
| 场景数 | 固定 10 场 | 5–7 章（00 序 / 01 录 / …） | ≤90 秒用 10 场；>90 秒用章节制 |
| 字幕 | `bottom: 44px` / 33px，底部 140px 不放图形 | `bottom: 92px` / 42px，中英两行 | 竖屏短内容用前者；横屏长片用后者 |
| 无口播文案密度 | 30–45 句 × ≤14 字 / 90 秒 ≈ 240–360 字每分 | 140–240 字每分 | ≤90 秒允许偏高；>2 分钟必须降到 240 以下 |
| 图形 | 每场一个主装置，不堆三个 | 全片一个母题贯穿，跨章复用 | 不冲突，互补：**场内只一个装置，跨场复用同一母题** |

字幕那条最容易翻车：按 plainframe 的 33px 写 42px 的版式，一行会折；反过来按 42px 写 33px 的位置，底部 140px 安全区会被吃掉。

---

## 三、其实一致的五条（不用纠结）

| 规则 | 两边做法 |
|---|---|
| 先演后命名 | 片名都不放在第 1 秒 |
| 系统字体 | 雅黑 / 宋体 / 楷体，都不用 Google Fonts 中文 |
| 无口播只留 BGM | 人声一律不要 |
| 一句一个动作 | 台词与动画同帧启动 |
| 数字要具体 | 12 毫秒 / 40.8 mph，不用「很快」「很多」 |

---

## 四、vibe-169 更严、应当采纳的两条

1. **片名时间**——它要求 6–24 秒才出片名；plainframe 是第 2 场（约 8–12 秒）出，落在区间内，但排第 2 场太靠前时会变成 6 秒，要盯一下。
2. **母题贯穿**——它要求全片一个母题（一个光点、一个圆环、一颗骰子），plainframe 的「每场一个装置」没有这条约束，长片容易散成 PPT。

两条已经并进 `docs/流程/锚词与重拍.md`，这里只记出处。

---

## 五、检查工具的分工（三者不重叠）

| 工具 | 管什么 | 什么时候跑 |
|---|---|---|
| `hyperframes lint` / `check` | 组合契约：`data-*` 属性、时间线注册、素材引用 | 每次改完 HTML |
| `tools/qa.py` | 成片：分辨率、音轨、黑屏、静止超过 2 秒 | 出片后 |
| `tools/contact_sheet.py` | 人眼复核：接触表、单帧落盘 | 出片后逐场看 |

出片前三个都要过；只过一个不算数。
