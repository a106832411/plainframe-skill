# 风格库（18 套）

> 从 `SKILL.md` 第二节搬出来的，这里是唯一权威。加风格只改这一篇和 `_tools/gen_styles.py`。

选一套贯穿全片。每套给：底色 / 主色 / 强调色 / 字体 / 图形语汇 / 动效语汇 / 适合题材。

**选风格的口径**：题材决定风格，不要反过来。机制 / 数据 → 示波器或蓝图；人文 / 历史 → 鎏金暗场或复古丝印；抽象 / 氛围 → 极光；年轻 / 网络 → 霓虹。


### A. 鎏金暗场

| 项 | 值 |
|---|---|
| 底 | `#0B0908` → `#140F0B` 渐变 |
| 主色 | 金 `#DDBD74` |
| 强调 | 朱 `#D9583C` |
| 正文 | 象牙 `#E8E3D9` |
| 字体 | 宋体（标题）/ 黑体（正文） |
| 图形 | 细金线、印章方块、同心圆、刻度、纸张纹理 |
| 动效 | 金线描边、印章落下、缓慢推镜、微光呼吸 |
| 适合 | 人文、历史、定律、深时间、情绪 |

### G. 黑板粉笔

| 项 | 值 |
|---|---|
| 底 | 板绿 `#1E2A24`（中心略亮，四周压暗） |
| 主色 | 粉笔白 `#EDEDE3` |
| 强调 | 粉笔黄 `#F2C14E` |
| 字体 | **楷体**（KaiTi / STKaiti），正文可用等宽 |
| 图形 | 手画圈、下划线、箭头、粉笔灰、板擦痕、粉笔槽 |
| 动效 | 逐笔写出（clip 横向擦）、描线、轻微手抖 |
| 适合 | 推导、教学、汉字/语言、需要「有人在你面前写」的题材 |

粗糙边缘的做法：给文字/线条套一个 SVG 滤镜
`feTurbulence(fractalNoise, 0.9) + feDisplacementMap(scale 2.6)`，
粉笔的颗粒感就出来了，不需要贴图。

**选风格的口径**：题材决定风格，不要反过来。机制/数据 → C 或 D；人文/历史 → A 或 B；抽象/氛围 → F；年轻/网络 → E。
