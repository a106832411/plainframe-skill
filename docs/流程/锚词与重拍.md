# 锚词与 17 秒重拍

> 借鉴来源：`hyperframes-vibe-169`（第三方技能；上游 HyperFrames 由 HeyGen 开源，Apache-2.0）。
> 只搬「结构层」，不搬那套技能的框架契约——我们这条线仍然是 `base.tpl` + `build.py` + `index.html`。

## 这一节管什么

`docs/流程/母版与流程.md` 的六母版管「这一段讲什么」；锚词管「全片钉在哪四个字上」。

两者不冲突：**先选母版，再选锚词**。母版决定段落顺序，锚词决定高潮落在哪一秒、观众带走哪个词。

## 一、锚词

**定义**：2–6 个字，是机制落在观众处境里的那个瞬间，不是机制的名字。

| 原理 | 锚词 | 开头它是困境 | 结尾它被反转 |
|---|---|---|---|
| 运动后效 | 原地 | 拼命跑，却还在原地 | 不是你没动，是眼睛在补偿 |
| 沉没成本 | 舍不得 | 越舍不得，越陷越深 | 及时止损也是一种获得 |
| 幸存者偏差 | 看不见的人 | 你只看到站着的 | 学会去数没站着的 |

**三个标准，缺一条就换词**：

1. **代入感**——观众一看觉得「这说的是我」；
2. **概括性**——一个词能收住整条片；
3. **可反转**——结尾能把它从困境改写成理解。

**自检**：把锚词单独拎出来问「这说的是我吗」。答不上来，说明你在讲术语。

**和标题的关系**：标题末句、片中大字、片尾金句，三处应当是同一个词。三处不一致，观众记不住。

## 二、17 秒重拍

强节奏、卡点、纪录片式叙事时用。**前提是先实测音乐**——17 秒是某首具体配乐的换气点，不是常数。

| 时间 | 画面 | 声音 |
|---|---|---|
| 16.4–16.9 | 所有元素淡出，整体收暗 | 换气，接近静音 |
| 16.9–17.0 | 静止约 3 帧 | 完全静默 |
| 17.0 | 亮起或墨晕炸开；**锚词砸出**，约占画宽 1/3；一圈光晕从中心扩散 | 重拍砸下 |
| 17.6 | 锚词下方浮出小字：术语名（中英） | 余韵 |
| 17.6–20 | 只做极轻微呼吸感（缩放 / 光脉） | 保持安静，不要填满 |

- 重拍点误差不超过 2 帧；
- 全片最多两次大爆点，第二次放在中段命名处，小一号；
- 「换气 → 静默 → 砸下」这三拍位置固定，片长变长只拉长后面的解释段。

**没有配乐时怎么办**：自己定一个重拍点，放在 40–90 秒之间（观众还没走、你又已经讲够铺垫），同样只做「收暗 → 静默 → 砸出」三拍。

## 三、结构选型（每个位置四选一）

### 钩子（0–3 秒）

| 类型 | 适合 | 句式 |
|---|---|---|
| 反常识结论 | 主题本身有认知反差 | 「热水灭火比冷水快，九成人都反了」 |
| 灵魂提问 | 生活痛点、好奇心 | 「为什么加油站禁止打手机？真相不是你想的那样」 |
| 现象悬念 | 有视觉奇观 | 先给画面，不说原因 |
| 数字冲击 | 数据反差强烈 | 「你的手机里，藏着超过 1000 种细菌」 |

原则：主题越反常识越用第一种，越贴生活越用第二种。可以组合，但核心只留一个。

### 主体

| 组织逻辑 | 适合 | 逻辑链 |
|---|---|---|
| 分点拆解 | 原理、常识 | 抛问题 → 分 2–3 点 → 每点配画面 |
| 递进推理 | 现象解释 | 现象 → 表层原因 → 底层原理 → 影响 |
| 实验验证 | 动手、硬核 | 猜想 → 材料 → 过程 → 现象 → 原理 |
| 辟谣纠偏 | 误区 | 大众误区 → 指错 → 正确结论 → 依据 |

### 结尾（最后 5–10 秒）

| 方式 | 适合 | 句式 |
|---|---|---|
| 总结强化 | 干货、密度高 | 一句话提炼核心结论 |
| 互动引导 | 想拉评论 | 开放式提问 |
| 留钩关注 | 系列内容 | 预告下期 |
| 价值延伸 | 生活实用 | 补一个应用场景 |

### 时长三档

| 档位 | 结构 | 节奏 |
|---|---|---|
| 15–30 秒 | 钩子 + 核心结论 + 极简解释 + 收尾 | 每 3–5 秒一个画面，不做论证 |
| 1–3 分钟 | 强钩子 → 2–3 个知识点 → 总结 | 每 10–15 秒换一个信息点，最常用 |
| 3–5 分钟 | 强悬念 → 背景 → 3 个分论 → 升华 | 每 30 秒一个小高潮 |

### 和六母版的对应

| 六母版 | 最接近的结构 |
|---|---|
| 猜谜 | 现象悬念型钩子 |
| 两难 | 反常识结论型钩子 |
| 痛点 | 灵魂提问型钩子 |
| 主线 | 递进推理式主体 |
| 闯关 | 实验验证式主体 |
| 轮转 | 分点拆解式主体 |

## 四、元素贯穿转场

原则：画面之间不做硬切，让**同一个元素**从上一镜长进下一镜。四种，按优先级：

| 方式 | 实现 | 例子 |
|---|---|---|
| 形状变形 | 前一镜的圆/方块缩放到下一镜的主图形尺寸，颜色渐变过去 | 一个圆变小变暖，成为下一镜的烛火 |
| 线条延伸 | 一条线向右延伸出画，下一镜从左边延伸进来 | 横线变成地平线 |
| 细节推近 | 镜头推到某个细节，该细节铺满画面后展开成下一镜 | 墨滴的扩散纹铺满，展开成漩涡 |
| 色彩过渡 | 前一镜的主色区域放大铺满，渐变到下一镜的主色 | 红光亮起，落到红色调的新场 |

```js
// 形状变形：前一镜末尾缩小淡出，后一镜开头从同尺寸放大
tl.to("#a", { scale: 0.1, opacity: 0, duration: 0.3 }, endA - 0.3);
tl.fromTo("#b", { scale: 0.1, opacity: 0 }, { scale: 1, opacity: 1, duration: 0.4 }, startB);

// 细节推近：推到 5 倍铺满，下一镜从 5 倍缩回
tl.to("#detail", { scale: 5, duration: 0.4, ease: "power2.in" }, endA - 0.4);
tl.fromTo("#new", { scale: 5 }, { scale: 1, duration: 0.5, ease: "power2.out" }, startB);
```

**硬约束**：转场 ≤ 0.5 秒；前后两景重叠不超过 0.2 秒；闪白、叠化只是辅助，不能当主要手段；禁止硬切。

## 五、世界与厂牌

拆过四条爆款（`docs/参考/参考-Vibe知识大赏.md`）之后最有用的一条区分：

- **世界可以换**：底色、介质、图形语汇，按年代或段落换；
- **厂牌不能换**：片名卡版式、署名、配乐、字幕习惯，全片一致。

| 世界 | 底 | 适合 |
|---|---|---|
| 鎏金暗场 | 近黑 + 象牙 + 金，四角压暗 | 一门学问的编年史：年份 + 人 + 问题 |
| 寓言 | 每场一幅扁平插画 | 一个行为或心理机制 |
| 夜曲 | 蓝黑夜空 + 细星点 + 一个光点 | 一个抽象概念 |

**底色随年代走**是最省力的一招：1932 用暖棕黑、1974 用墨绿、1986 用深紫，只换一层径向渐变，观众立刻觉得「换了地方」。做法：铺三层全屏 div（`tintWarm` / `tintGreen` / `tintViolet`），每层一个径向渐变、初始 `opacity: 0`，只在章节边界交叉淡入淡出，主体颜色一律不动。

**结尾回到开头**：同一个画面再出现一次，但意思变了。这是四条片都做的事，也是最便宜的记忆点。

## 六、什么时候用这一套

| 情况 | 用不用 |
|---|---|
| ≤ 40 秒、要求强节奏 / 卡点 | 用锚词 + 17 秒重拍，六母版让位 |
| 1–3 分钟、常规科普 | 六母版为主，锚词只取「三处同词」那一条 |
| > 3 分钟 | 六母版 + 每 30 秒一个小金句，重拍最多两次 |
| 纯机制演示、无情绪落点 | 不用锚词，硬套会显得刻意 |
