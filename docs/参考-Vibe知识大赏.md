---

## 一、画面密度

| 规则 | 出处 | 我们的做法 |
|---|---|---|
| 相邻 2 秒必须有肉眼可见的变化 | vibe-knowledge-video | 每句台词至少带一个动作（画线/计数/位移/翻转），没有就改句 |
| 文字停留 > 4 秒时，必须有微动效 | 同上 | 长句（>4 秒）配持续运动：水位、指针、粒子 |
| 静止画面 < 25% | 同上（实测均值） | 全片抽查：连续两场都静止就要改 |

**判据**：随便截两帧相差 2 秒的画面，如果完全一样，就是错的。

---

## 二、转场

参考项目里一条硬规定：**转场必须从内容里长出来**。

| 不许 | 改成 |
|---|---|
| 默认淡入淡出 | 一条线变成地平线、卡片飞出重组、水面涨过画面 |
| 所有元素同时入场 | 依次入场，前一个动作没停，后一个已经开始 |
| 弹跳缓动 | 只用 `power` / `expo` 系（弹跳会毁掉纪录片感） |

我们现在的做法是“先出后进 + 0.03 秒空档”，这是底线；再往上一步是让**画面元素本身**变成转场（例：曲线末尾变成下一页的坐标轴）。

---

## 三、配图 vs 讲解（最重要的一条）

vibe-knowledge-film 里有一个反例值得记住：

> 讲蛋白质的片子，全片主体是“一串星点连成的折线”。字幕说“只换掉第 6 个，形状就变了”，折线换了个卷法、变成玫红色。
> 颜色、字体、节奏都对，但观众从头到尾没见过蛋白质是什么。

**判据三条**：

1. 屏上的主体，叫得出日常名字（“一串珠子”“一个中间凹下去的红细胞”），不是“点、线、圈、方框”
2. 句子里的动词，屏上真的做（“砍掉一半”就盖住一半）
3. 把这个主体换给别的文案也成立 → 它只是配图，不是讲解

**应用**：每条分镜自查这三条；不满足就换形象，或者改句子。

---

## 四、该画的画，该停的停

参考片里大约 **每五句有一句不配新画面**——提问、命名、结论、引文，这些句子让画面停住。

我们常犯的错是每句都换图，结果观众一直在重新认画面，没有时间想。

**做法**：标注哪些句子“不画”，只留文字和背景微动。

## 五、六维自检（他们用 1–10 打分，低于 8 就改）

| 维度 | 看什么 |
|---|---|
| 前 2 秒抓人 | 第一帧有没有具体的东西/动作 |
| 手机缩放可读 | 缩到 1/4 大小，主标题还认得出吗 |
| 动作自然 | 有没有匀速滑动、有没有空拍 |
| 画面新鲜度 | 每 2–4 秒有没有新东西 |
| 构图 | 主体位置、留白、文字区干净 |
| 声画对位 | 说到哪个词，画面在动哪个东西 |

我们加两条：**文字不压图形**、**同句不重复出现**。

---

## 六、他们的标题/钩子公式

`vibe-knowledge-video` 的发布模板：

```
Vibe知识大赏 | 《标题》一句话钩子？
[2-3 句：一个年份 + 一个人名 + 一个反直觉结论]
#vibe知识大赏 #AI把知识拍成大片了 [主题词]
```

和我们现在用的「不是……是因为……」是同一族：**先给现象，再给反直觉，最后给机制**。

## 七、我们不改的地方

| 他们 | 我们 |
|---|---|
| 无配音，纯字幕 + BGM | 有口播配音，字幕只做补充 |
| 2:00–2:45 | 75–90 秒 |
| 30fps 逐帧 Canvas | GSAP 时间线 + HTML/SVG |
| 文献再现、双语字幕 | 单语，图形为主 |

风格可以不同，判断标准可以共用。

## 八、无口播路线（本仓库已切换）

参考 `vibe-explainer-video` 的拍表，换成我们自己的时长。核心差别：

| | 口播版 | 无口播版 |
|---|---|---|
| 文案 | 说出来的话 | **读的字幕**，一句一行，2–3 秒 |
| 时长来源 | 音频实测 | **字数 ÷ 4.2 字/秒** |
| 节奏锚点 | 句子 | **拍**（BPM） |
| 音频 | 人声 + BGM 闪避 | **只有 BGM**，首尾淡入淡出 |
| 文案密度 | 20–30 句 | **30–45 句**（同样时长） |

### 结构模板（90 秒 = 150 拍 @ 100 BPM）

| 拍 | 秒 | 段 | 内容 |
|---|---|---|---|
| 0–12 | 0–7.2 | 活封面 + 钩子 | 第 0 帧就是封面；3 秒内落反常识结论 |
| 12–18 | 7.2–10.8 | 片名卡 | 片名 + 一行副题 |
| 18–40 | 10.8–24 | 第一案例 | 具体的人、地点、年份 |
| 40–70 | 24–42 | 机制 | 一图讲清 |
| 70–80 | 42–48 | 预测题 | 先猜后揭晓，倒数 3-2-1 |
| 80–110 | 48–66 | 揭晓 + 反转 | 收口上一段 |
| 110–130 | 66–78 | 落到生活 | 边界、条件 |
| 130–145 | 78–87 | 金句 | 能截图转发的那一句 |
| 145–150 | 87–90 | 说明卡 | 出处、示意声明 |

### 三条硬规则

1. **一句一行，2–3 秒**，每句只说一件事；超过 14 字就拆
2. **全片只有 3 个重音**：钩子结论、揭晓、金句，其余都是轻声
3. **字幕区 y ≥ 920**，主体放 y 150–860，同屏只有一个主角

### 我们改了什么

- `templates/build.py`：加 `--novoice`，按字数估时长（`cps` 可配，默认 4.2 字/秒）
- `templates/mix.py`：无口播时只出 BGM，0.8 秒淡入淡出
- `gen_tts.mjs`：保留，但只在口播版里用
